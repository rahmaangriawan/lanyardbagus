# Lanyard Bagus

Monorepo starter for a public website + CMS:

- SvelteKit public site and admin panel
- Fastify REST API
- Prisma + MySQL
- SCSS styling
- GSAP + Lenis on public pages

## Local setup

1. Copy `.env.example` to `.env`
2. Start MySQL
3. Install dependencies
4. Run database migration and app dev servers

## Scripts

- `npm run dev:web`
- `npm run dev:api`
- `npm run build:web`
- `npm run build:api`
